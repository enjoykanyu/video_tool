# B站AI双语字幕

为B站视频添加AI生成的中英文对照字幕，支持实时翻译与滚动显示。

## 功能
- 优先读取 B 站 CC 字幕轨道；轨道不可用时，视频 `BV1c1qvBFEVw` 使用仓库内已有的英文 SRT 转录稿（仅第 1 P）
- 英文原文提取后立即按视频时间轴显示；配置 API Key 后分批结合相邻上下文翻译成中文
- 拖动字幕栏的手柄可将字幕移到网页任意可见位置，位置保存在本地；支持下载完整双语 TXT 和 SRT

## 使用方法

1. 打开 Chrome 的「扩展程序」页面（`chrome://extensions/`），开启「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本文件夹
3. 点击扩展图标，配置 API：
   - **服务商**：选择「阿里云百炼」
   - **Base URL**：`https://dashscope.aliyuncs.com/compatible-mode/v1`
   - **API Key**：你的百炼 API Key
   - **模型**：填写该服务商实际可用的兼容模型名称
4. 点击「测试连接」，成功后保存
5. 打开带字幕的 B 站视频，字幕会自动提取、翻译，并随播放进度滚动显示中英文

## 字幕来源
- 优先使用 `/x/player/v2` 获取播放器字幕轨道；失败时尝试页面内的字幕轨道
- 指定视频 `BV1c1qvBFEVw` 的第 1 P 使用项目内现有英文 SRT 后备文件；其他视频没有可用轨道时会如实提示
- 画面中烧录的文字不等于 CC 字幕。对没有独立轨道、也没有本地转录稿的视频，需要另行提供语音识别或 OCR 转录稿

视频时长或分 P 如与本地转录稿不一致，请核对英文时间轴后再使用下载文件。翻译失败时英文原文仍可显示和导出。

API Key 仅保存在浏览器本地 `chrome.storage.local`，不会上传。
