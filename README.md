# B站AI双语字幕

为B站视频添加AI生成的中英文对照字幕，支持实时翻译与滚动显示。

## 功能
- 播放前可选择：导入 SRT、加载当前分P的本地记录、在线提取英文 CC 并翻译
- 缓存严格按 `BV号 + 分P` 隔离；在线结果额外保存 `cid`、分集标题和时长，避免串集
- 导入及本地记录不会调用大模型；在线提取才会分批翻译，并持续缓存进度
- 字幕框默认显示当前行及上下各一行，可拖到网页任意位置，也可拖动右下角调整大小
- 支持下载完整 TXT 和 SRT
- 可在扩展设置中将字幕字号调整为 14–40px，打开中的视频会立即应用新字号
- 可调字幕背景透明度，默认半透明以减少对视频画面的遮挡
- 可在字幕来源中选择“OCR提取硬字幕”，先手动圈选字幕区域，再识别中英文烧录字幕，实时生成并加载带时间轴的双语 SRT
- 可选择“语音识别英文”，按约 10 秒切片实时提取音轨，结合已识别上下文即时翻译并生成双语 SRT

## 使用方法

1. 打开 Chrome 的「扩展程序」页面（`chrome://extensions/`），开启「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本文件夹
3. 点击扩展图标，配置 API：
   - **服务商**：选择「阿里云百炼」
   - **Base URL**：`https://dashscope.aliyuncs.com/compatible-mode/v1`
   - **API Key**：你的百炼 API Key
   - **模型**：填写该服务商实际可用的兼容模型名称
4. 点击「测试连接」，成功后保存
5. 打开视频，从页面顶部的来源栏选择导入、本地记录或在线提取

## 字幕来源
- 使用当前浏览器的 B 站登录态，依次查询 `/x/player/v2` 和 `/x/player/wbi/v2`，且只接受明确标记为英文的轨道
- 若轨道存在但下载 URL 为空，会读取播放器实际加载的字幕资源；仅接受 B 站域名、英文内容且时长匹配的完整字幕
- 在线字幕 URL、分P和时长都会校验；不会退回其他语言、其他分集或项目内的静态字幕
- 画面中烧录的文字不等于 CC 字幕。对没有独立轨道、也没有本地转录稿的视频，需要另行提供语音识别或 OCR 转录稿

导入文件若明显长于当前视频会被拒绝。翻译失败时英文原文仍会缓存，可从本地记录直接加载和导出。

API Key 仅保存在浏览器本地 `chrome.storage.local`，不会上传。

### OCR 硬字幕

在“字幕来源”中点击“OCR提取硬字幕”后，扩展会暂停视频，先拖动圈选字幕区域。之后只截取该区域，按约 2.5 秒间隔调用支持视觉输入的模型识别英文和中文；每约 10 秒刷新一次当前双语字幕和缓存，完成后生成完整 SRT。识别完成后可以直接滚动播放、导出 SRT，或从本地记录再次加载。

OCR 会产生多次视觉模型请求，视频越长成本越高；当前标签页必须保持可见，所选模型也必须支持图片输入。它适合提取已经烧录在画面中的字幕，不适合替代专业语音识别。

### 语音识别英文

“语音识别英文”会从播放器音轨按约 10 秒切片，识别一段就结合前文上下文翻译一段，并立即刷新字幕面板和缓存，不需要等视频结束。为保证音频片段边界准确，处理每个片段时视频会短暂停顿；整个过程仍需保持标签页可见。OpenAI 使用 `whisper-1`，百炼使用支持音频输入的 `qwen-audio-turbo`，具体可用性取决于服务商账号和模型权限。

## 没有英文字幕时的语音识别方案

当前版本只会读取 B 站已有的英文 CC 字幕，不会自动从视频音轨做语音识别。要支持“无英文字幕 → 英文识别 → 中文翻译 → 中英双语 SRT”，可以保留本扩展作为显示端，新增一个识别流程：

1. 获取当前分 P 的音频（浏览器扩展不能稳定地直接下载 B 站媒体流，通常需要本地服务或用户提供音频文件）。
2. 使用 Whisper/faster-whisper 等 ASR 模型生成带时间戳的英文初稿；需要按词或片段时间戳，才能与视频滚动同步。
3. 对英文初稿做断句、标点和专有名词校正，再调用现有翻译接口生成中文。
4. 复用现有字幕数据结构 `{from, to, content, translation}`，即可继续显示和导出双语 SRT。

准确性取决于音质、口音、背景音乐和模型大小；“准确”不能由翻译模型替代，需要 ASR 后处理和人工校对入口。推荐的工程拆分是 Chrome 扩展负责播放器同步/显示，本地 Python 服务负责音频提取、Whisper 识别和分段，现有 `background.js` 继续负责翻译 API 调用。该功能目前尚未实现。
